# FE Skill - REVIEW

## Mục tiêu
Đánh giá mức độ khớp spec UI và phát hiện lỗi ảnh hưởng flow người dùng.

## Checklist review
- [ ] So UI flow với docs FE (public + admin).
- [ ] Kiểm tra unauthorized redirect và role-based access.
- [ ] Kiểm tra submit form: disable khi đang gửi, báo lỗi rõ.
- [ ] Kiểm tra dữ liệu hiển thị đúng format/field.
- [ ] Kiểm tra trạng thái loading/empty/error tồn tại.
- [ ] Kiểm tra backward navigation và deep-link routes.
- [ ] Kiểm tra build pass không warning nghiêm trọng.

## Output
- Findings theo severity + file ref + ảnh hưởng + fix.
