# Docs Skill - CREATE

## Mục tiêu
Tạo tài liệu rõ ràng, nhất quán, dùng được cho dev và test ngay.

## Checklist thực thi
- [ ] Mỗi endpoint có: mục tiêu, auth, request, response, errors.
- [ ] FE screen có: route, state, API calls, validation, edge cases.
- [ ] DB docs có: schema, quan hệ, ràng buộc, index gợi ý.
- [ ] Có phần runbook: setup/run/test.
- [ ] Thuật ngữ thống nhất giữa FE/BE/DB docs.

## Output
- File docs mới/cập nhật
- Mục nào thay đổi contract
