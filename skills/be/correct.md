# BE Skill - CORRECT

## Mục tiêu
Sửa findings theo mức ưu tiên rủi ro và đảm bảo không tạo regression mới.

## Checklist sửa
- [ ] Chốt danh sách findings cần fix trong vòng này.
- [ ] Sửa Critical/High trước, không defer.
- [ ] Viết test regression cho lỗi vừa sửa.
- [ ] Re-run test target + smoke endpoints liên quan.
- [ ] So lại contract với docs sau khi sửa.
- [ ] Cập nhật docs nếu có thay đổi hành vi.
- [ ] Ghi rõ finding nào đã đóng/mở.

## Output
- Findings đã fix
- Findings còn lại + lý do
- Bằng chứng verify
