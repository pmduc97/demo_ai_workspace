# Test Skill - CREATE

## Mục tiêu
Thiết lập và bổ sung test để bao phủ luồng nghiệp vụ chính và lỗi quan trọng.

## Checklist thực thi
- [ ] Có setup test runner + scripts rõ ràng.
- [ ] Tổ chức test theo module (auth/posts/categories/admin/upload).
- [ ] Mỗi endpoint có test happy path.
- [ ] Có test unauthorized/forbidden/validation/not-found.
- [ ] Test data độc lập, deterministic.
- [ ] Có cleanup/rollback tránh ảnh hưởng chéo.
- [ ] Báo cáo coverage tạo được.

## Output
- Danh sách file test
- Cách chạy suite
- Coverage hiện tại
