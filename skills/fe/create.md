# FE Skill - CREATE

## Mục tiêu
Triển khai màn hình/flow đúng tài liệu, ổn định khi gọi API, và bảo đảm trải nghiệm người dùng cơ bản.

## Input bắt buộc
- Screen spec (`demo_docs/fe/*.md`)
- API mapping liên quan
- Quy tắc phân quyền route

## Checklist thực thi
- [ ] Route/component đúng theo screen list.
- [ ] Guard auth/role hoạt động đúng.
- [ ] Form có validate phía client tối thiểu.
- [ ] API call có loading/success/error states.
- [ ] Xử lý empty state khi không có dữ liệu.
- [ ] Không crash khi API trả lỗi/time-out.
- [ ] Điều hướng sau hành động đúng (create/edit/login/logout).
- [ ] Responsive cơ bản desktop/mobile.
- [ ] Đồng bộ naming field với API response.
- [ ] Cập nhật docs FE nếu flow đổi.

## Output
- Route map thay đổi
- Components/pages thay đổi
- Hướng dẫn verify luồng tay
