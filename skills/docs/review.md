# Docs Skill - REVIEW

## Mục tiêu
Phát hiện tài liệu lỗi thời hoặc mâu thuẫn so với code hiện tại.

## Checklist review
- [ ] Endpoint trong docs có tồn tại trong code.
- [ ] Status code/docs ví dụ đúng behavior thực tế.
- [ ] Role/permission docs khớp middleware.
- [ ] Tên field request/response khớp source.
- [ ] Các docs không mâu thuẫn lẫn nhau.
- [ ] Link chéo tài liệu còn hợp lệ.

## Output
- Danh sách mismatch theo severity + file ref + đề xuất sửa
