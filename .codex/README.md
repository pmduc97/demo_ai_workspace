# Codex Workspace Context

Tài liệu ngữ cảnh cho agent nằm ở README gốc của workspace.

- Nguồn chính: `../README.md`
- Vui lòng đọc `../README.md` để nắm:
  - Mục tiêu project
  - Tech stack
  - Cấu trúc thư mục
  - Trạng thái hiện tại
  - Bước tiếp theo

Ghi chú: File này chỉ đóng vai trò điều hướng, không lặp lại nội dung chi tiết để tránh lệch phiên bản.
