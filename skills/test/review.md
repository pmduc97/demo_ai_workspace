# Test Skill - REVIEW

## Mục tiêu
Đánh giá chất lượng test: độ phủ, tính ổn định, độ tin cậy assert.

## Checklist review
- [ ] Coverage có chạm các branch quan trọng?
- [ ] Có thiếu case negative path nào?
- [ ] Test có phụ thuộc thứ tự chạy?
- [ ] Có flaky do thời gian/random/shared state?
- [ ] Assertions có đủ chặt cho API contract?
- [ ] Test chạy được local lặp lại >= 2 lần ổn định?

## Output
- Gaps + flaky risks + đề xuất bổ sung
